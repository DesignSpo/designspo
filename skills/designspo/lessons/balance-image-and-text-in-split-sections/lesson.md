Most two-column layouts put an image on one side and copy on the other. This layout is so popular because it's naturally visually balanced. The image gives the copy context and the copy sits neatly near the image.

But when an image is smaller or larger than the copy, the section looks unbalanced. It can leave a lot of white space on one side of the section which, ironically, draws attention away from the content.

The fix for this is simple. Let the image take up the full height of the container so that it sits evenly with the copy. This might take a little bit of extra care, since the focal point of the image will need to be centered to prevent different screens showing different sizes of the image.
