A single typeface is usually enough to create a sense of visual hierarchy in your design if you choose one strategically.

Most modern typefaces (especially Grotesque and Sans-serif ones) come with many options for weight and optical size. That means you don't need to select multiple typefaces to create hierarchy.

Differences in size, weight, letter-spacing, optical size, and color all create differences in text that the eye has an easy time following.

Plenty minimalist websites push these even further, using only a few weights and very small differences in size to create a sense of hierarchy. The eye still has no problem tracking it. This isn't always the best approach but it shows you what's possible.

If you're designing something more classical, you may be stuck with less options for font variation. Times New Roman for example only has `Regular` and `Bold` weights. You can still use size, italics, or letter-spacing to create a sense of hierarchy but in this case many designers do opt to use a second typeface.
