Before, with no style guide, they're a mess: three near-identical blues called blue, blue-2 and primary, type sizes of 32, 30, 17 and 16px, spacing of 22, 24, 25 and 64px, and three classes for the same button. After, a plain Style guide page with fewer values, each with its name and a short note on when to use it, like brand-500 for buttons, heading-l for page titles, space-24 for card gaps and btn--outline for other actions.
---

A design system that lives only in your head will break the moment someone else edits the site, or when you come back to it months later. You’ll have to guess which color or class to use, and small differences start to creep in.

Put every token, class and component on a few reference pages, with a short note on when to use each one. A style guide page might show your color swatches, type sizes, spacing scale and buttons, each with its name. It doesn’t need to be fancy. A plain page that people can actually find is often more useful than a polished document nobody opens.
